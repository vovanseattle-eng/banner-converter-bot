# 🎬 Banner Converter Bot (60 FPS)

100% бесплатный Telegram-бот для мгновенной сборки и конвертации анимированных TGS / WEBM / WEBP стикеров и эмодзи в премиальные видеобаннеры 60 FPS (H.264 MP4).

## 🚀 Особенности
- **60 FPS Video Banner**: чистый цикл, экспорт без черных артефактов.
- **Составные баннеры (Multi-Emoji)**: склейка наборов эмодзи в единую надпись в RAM.
- **8 кинематографических видеофонов 60 FPS**: шёлк, сетка, плёночное зерно, топо-линии, боке/частицы, софит, сканлайн, капли дождя.
- **Умная перекраска (Recolor)**: сохранение 3D-теней и бликов через матрицу яркости.
- **1-Click палитра**: мгновенный выбор из 24 цветов по категориям (Классика, Яркие, Пастель, Неон) + поддержка названий на русском языке.
- **Собственный чистый Mini App**: встроенная спектр-палитра без рекламы.
- **Hardware Acceleration**: поддержка NVENC для ультрабыстрого рендера с 0% нагрузки на CPU.

## 🛠 Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```
2. Убедитесь, что установлен `ffmpeg` и доступен в `PATH`.
3. Настройте `.env`:
```env
BOT_TOKEN=ваш_токен_бота
PROXY_URL=http://127.0.0.1:10809 # опционально
WEBAPP_COLOR_PICKER_URL=https://color-picker-webapp.vercel.app
```
4. Запуск:
```bash
python bot.py
```
